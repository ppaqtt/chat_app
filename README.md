# 极简聊天室

一个基于 WebSocket 的实时聊天应用，支持多人在线聊天、表情包、输入状态提示、消息历史保存等功能。

## 🎯 功能特性

### 核心功能
- ✅ 实时消息发送和接收
- ✅ 多人在线聊天
- ✅ 在线用户列表显示
- ✅ 用户加入/离开系统通知

### 第一批功能
- 😊 **表情包支持** - 64 个常用表情，点击即可插入
- ✍️ **输入状态提示** - 显示"xxx正在输入..."
- 💾 **消息历史保存** - 自动保存最近 100 条消息
- ⏰ **完整时间戳** - 显示日期和时间
- 🌙 **黑暗模式切换** - 支持明亮/深色主题，自动保存偏好
- 💬 **消息回复功能** - 点击回复按钮，引用历史消息
- 📣 **@提及功能** - 输入@时显示用户选择，高亮提及
- 🔍 **聊天记录搜索** - 搜索历史消息，点击定位

### 第二批功能
- 🔄 **消息撤回** - 鼠标悬停显示撤回按钮，点击撤回消息
- 🖼️ **用户头像** - 根据昵称自动生成彩色头像，支持自定义上传
- 👥 **私聊功能** - 支持一对一私密聊天，区分群聊和私聊
- ⚙️ **用户资料设置** - 修改昵称、上传自定义头像
- 👍❤️😂 **消息反应功能** - 为消息添加表情反应
- 📎 **文件传输功能** - 上传任意文件，发送并下载

### 第三批功能
- 📷 **图片发送** - 支持发送图片，点击可放大查看
- 🏠 **多房间切换** - 支持创建和切换多个聊天室
- ✅ **消息已读状态** - 显示消息已读人数，点击查看详细列表
- 🌐 **消息翻译** - 支持中英互译，点击翻译按钮切换
- 📌 **消息置顶** - 重要消息置顶显示，顶部消息栏快速跳转
- 📞 **视频/语音通话** - 发起语音/视频通话，来电弹窗接听
- 📍 **位置共享** - 发送当前位置，地图预览，点击打开Google Maps

## 🛠️ 技术栈

- **前端**: HTML5 + CSS3 + JavaScript
- **后端**: Node.js
- **实时通信**: WebSocket (ws 库)
- **数据存储**: localStorage (客户端)

## 🚀 快速开始

### 环境要求
- Node.js (v14+)
- npm 或 yarn

### 安装步骤

1. **克隆项目**
   ```bash
   git clone <项目地址>
   cd simple-chat-app
   ```

2. **安装依赖**
   ```bash
   npm install
   ```

3. **启动服务器**
   ```bash
   npm start
   ```

4. **访问应用**
   打开浏览器访问 http://localhost:3000

### 使用方法

1. 打开 http://localhost:3000
2. 输入昵称，点击"进入聊天室"
3. 打开多个浏览器窗口，用不同昵称登录
4. 开始聊天！

## 🎨 界面预览

- **登录界面**: 输入昵称进入
- **聊天界面**: 
  - 顶部：标题 + 主题切换 + 搜索 + 个人设置 + 通话 + 在线用户 + 房间
  - 中部：置顶消息栏 + 消息区域（支持多种消息类型）
  - 底部：表情 + 图片 + 文件 + 位置 + 输入框 + 发送按钮

## 🔧 自定义

### 修改端口
编辑 `server.js` 第 8 行：
```javascript
const PORT = 3000;  // 修改为你的端口
```

### 添加表情
编辑 `app.js` 第 31 行的 `emojis` 数组：
```javascript
const emojis = ['😀', '😃', '...'];  // 添加更多表情
```

## 📝 开发说明

### WebSocket 消息类型

| 类型 | 方向 | 说明 |
|------|------|------|
| `login` | 客户端→服务器 | 用户登录 |
| `message` | 双向 | 聊天消息 |
| `imageMessage` | 双向 | 图片消息 |
| `fileMessage` | 双向 | 文件消息 |
| `locationMessage` | 双向 | 位置消息 |
| `privateMessage` | 双向 | 私聊消息 |
| `privateFileMessage` | 双向 | 私聊文件消息 |
| `typing` | 客户端→服务器 | 输入状态 |
| `stopTyping` | 客户端→服务器 | 停止输入 |
| `recall` | 客户端→服务器 | 撤回消息 |
| `readMessage` | 客户端→服务器 | 消息已读 |
| `createRoom` | 客户端→服务器 | 创建房间 |
| `joinRoom` | 客户端→服务器 | 加入房间 |
| `updateProfile` | 客户端→服务器 | 更新个人资料 |
| `addReaction` | 客户端→服务器 | 添加消息反应 |
| `pinMessage` | 客户端→服务器 | 置顶消息 |
| `unpinMessage` | 客户端→服务器 | 取消置顶 |
| `callOffer` | 客户端→服务器 | 发起通话请求 |
| `callAnswer` | 客户端→服务器 | 接受通话 |
| `callReject` | 客户端→服务器 | 拒绝通话 |
| `callEnd` | 客户端→服务器 | 结束通话 |
| `system` | 服务器→客户端 | 系统通知 |
| `loginSuccess` | 服务器→客户端 | 登录成功 |
| `messageRecalled` | 服务器→客户端 | 消息被撤回 |
| `messageRead` | 服务器→客户端 | 消息被已读 |
| `roomCreated` | 服务器→客户端 | 房间创建成功 |
| `joinedRoom` | 服务器→客户端 | 加入房间成功 |
| `reactionAdded` | 服务器→客户端 | 反应已添加 |
| `pinMessage` | 服务器→客户端 | 消息已置顶 |
| `unpinMessage` | 服务器→客户端 | 消息已取消置顶 |
| `pinnedMessages` | 服务器→客户端 | 初始化置顶消息 |
| `profileUpdated` | 服务器→客户端 | 资料已更新 |
| `callOffer` | 服务器→客户端 | 收到通话邀请 |
| `callAnswer` | 服务器→客户端 | 通话已被接受 |
| `callReject` | 服务器→客户端 | 通话已被拒绝 |
| `callEnd` | 服务器→客户端 | 通话已结束 |

### 数据存储

- **localStorage**: 保存聊天记录（最多 100 条）和主题偏好
- **服务器内存**: 保存当前在线用户列表、房间信息、消息历史、置顶消息
