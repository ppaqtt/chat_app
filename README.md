# 极简聊天室

一个基于 WebSocket 的实时聊天应用，支持多人在线聊天、表情包、输入状态提示、消息历史保存等功能。

## 🎯 功能特性

### 核心功能
- ✅ 实时消息发送和接收
- ✅ 多人在线聊天
- ✅ 在线用户列表显示
- ✅ 用户加入/离开系统通知

### 第一批功能
- 😊 **表情包支持** - 64 个常用表情，点击即可插入
- ✍️ **输入状态提示** - 显示"xxx正在输入..."
- 💾 **消息历史保存** - 自动保存最近 100 条消息
- ⏰ **完整时间戳** - 显示日期和时间
- 🌙 **黑暗模式切换** - 支持明亮/深色主题，自动保存偏好
- 💬 **消息回复功能** - 点击回复按钮，引用历史消息
- 📣 **@提及功能** - 输入@时显示用户选择，高亮提及
- 🔍 **聊天记录搜索** - 搜索历史消息，点击定位

### 第二批功能
- 🔄 **消息撤回** - 鼠标悬停显示撤回按钮，点击撤回消息
- 🖼️ **用户头像** - 根据昵称自动生成彩色头像，支持自定义上传
- 👥 **私聊功能** - 支持一对一私密聊天，区分群聊和私聊
- ⚙️ **用户资料设置** - 修改昵称、上传自定义头像
- 👍❤️😂 **消息反应功能** - 为消息添加表情反应
- 📎 **文件传输功能** - 上传任意文件，发送并下载

### 第三批功能
- 📷 **图片发送** - 支持发送图片，点击可放大查看
- 🏠 **多房间切换** - 支持创建和切换多个聊天室
- ✅ **消息已读状态** - 显示消息已读人数，点击查看详细列表
- 🌐 **消息翻译** - 支持中英互译，点击翻译按钮切换
- 📌 **消息置顶** - 重要消息置顶显示，顶部消息栏快速跳转
- 📞 **视频/语音通话** - 发起语音/视频通话，来电弹窗接听
- 📍 **位置共享** - 发送当前位置，地图预览，点击打开高德地图

### 第四批功能
- 🔄 **消息编辑** - 允许修改已发送消息，显示(已编辑)标记
- 📤 **消息转发** - 转发消息到其他房间或私聊用户
- ⭐ **消息收藏/星标** - 收藏重要消息，随时在收藏面板查看
- ⚡ **快捷回复** - 保存常用短语，一键发送
- 👥 **@全体成员** - 快速提醒所有人注意
- 🔔 **浏览器通知** - 新消息或来电时的桌面通知
- 🔍 **高级搜索** - 按用户、星标状态等筛选聊天记录
- 💾 **消息导出** - 导出聊天记录为 JSON 文件
- 🎨 **自定义背景** - 预设渐变背景 + 自定义图片
- 🚫 **黑名单功能** - 拉黑用户，隐藏其消息

### 第五批功能（高级扩展）
- 📹 **视频通话（已修复）** - 真正调用摄像头，WebRTC 视频流传输
- 🎤 **语音通话（已修复）** - 真正调用麦克风，WebRTC 音频流传输
- 📊 **消息统计** - 显示总消息数、今日统计、在线时长等
- ⏰ **定时提醒** - 设置提醒时间，到期弹出通知
- 🔔 **消息提醒声音** - 4种提示音可选，自定义开启/关闭
- ⌨️ **快捷键支持** - Ctrl+Enter发送、Esc关闭、↑↓切换等
- 📢 **群公告** - 管理员发布公告，实时同步给所有成员
- 🗳️ **投票功能** - 创建单选/多选投票，实时显示结果
- 👤 **用户资料卡** - 点击用户名查看详情，快速私聊/拉黑
- 🏷️ **消息标签** - 为消息添加重要/待办/问题/想法标签
- 🛡️ **消息防骚扰** - 关键词过滤、敏感词屏蔽、消息举报
- 📱 **多设备同步** - 设备管理、跨设备同步偏好设置
- 🔐 **私聊加密** - AES加密保护私聊消息安全
- 🤖 **AI助手** - 5种角色模式，智能回复，上下文保持
- 🎯 **智能推荐** - 分析用户习惯，推荐回复内容
- 🎨 **气泡样式** - 6种预设样式，自定义颜色和圆角
- ✨ **消息动画** - 滑入动画、成功动画、撤回动画效果
- 🖼️ **消息预览** - 图片大图预览、文件信息预览
- 🌈 **彩色用户名** - 随机颜色分配，VIP特殊标识
- 💾 **聊天记录备份** - 导出为HTML/JSON/文本，定期自动备份

## 🛠️ 技术栈

- **前端**: HTML5 + CSS3 + JavaScript
- **后端**: Node.js
- **实时通信**: WebSocket (ws 库)
- **音视频通信**: WebRTC API
- **数据存储**: localStorage (客户端)
- **加密**: CryptoJS AES

## 🚀 快速开始

### 环境要求
- Node.js (v14+)
- npm 或 yarn
- 现代浏览器（支持 WebSocket、WebRTC）

### 安装步骤

1. **克隆项目**
   ```bash
   git clone <项目地址>
   cd chat_app
   ```

2. **安装依赖**
   ```bash
   npm install
   ```

3. **启动服务器**
   ```bash
   npm start
   ```

4. **访问应用**
   打开浏览器访问 http://localhost:3000

### 使用方法

1. 打开 http://localhost:3000
2. 输入昵称，点击"进入聊天室"
3. 打开多个浏览器窗口，用不同昵称登录
4. 开始聊天！

## 🎨 界面预览

- **登录界面**: 输入昵称进入
- **聊天界面**:
  - 顶部：标题 + 主题切换 + 搜索 + 个人设置 + 通话 + 在线用户 + 房间 + 各种功能按钮
  - 中部：公告横幅 + 置顶消息栏 + 消息区域（支持多种消息类型）
  - 底部：表情 + 图片 + 文件 + 位置 + @all + 输入框 + 发送按钮

## ⌨️ 快捷键

- `Ctrl+Enter` - 发送消息
- `Esc` - 关闭当前弹窗/面板
- `↑/↓` - 在快捷回复面板中切换选项
- `/` - 快速打开搜索
- `Ctrl+S` - 打开设置
- `Ctrl+H` - 显示快捷键提示

## 🔧 自定义

### 修改端口
编辑 `server.js` 第 8 行：
```javascript
const PORT = 3000;  // 修改为你的端口
```

### 添加表情
编辑 `app.js` 的 `emojis` 数组：
```javascript
const emojis = ['😀', '😃', '...'];  // 添加更多表情
```

### 配置高德地图
编辑 `app.js` 中的地图相关代码，替换为您的高德地图 API Key

### WebRTC 配置
如需更好的 NAT 穿透，可以配置 STUN/TURN 服务器

### 数据存储

- **localStorage**: 保存聊天记录、主题偏好、自定义设置、黑名单、星标消息、快捷回复、用户颜色、背景设置等
- **服务器内存**: 保存当前在线用户列表、房间信息、消息历史、置顶消息、投票数据、公告数据
