# 极简聊天室

一个基于 WebSocket 的实时聊天应用，支持多人在线聊天、表情包、输入状态提示、消息历史保存等功能。

## 🎯 功能特性

### 核心功能
- ✅ 实时消息发送和接收
- ✅ 多人在线聊天
- ✅ 在线用户列表显示
- ✅ 用户加入/离开系统通知

### 第一级功能
- 😊 **表情包支持** - 64 个常用表情，点击即可插入
- ✍️ **输入状态提示** - 显示"xxx正在输入..."
- 💾 **消息历史保存** - 自动保存最近 100 条消息
- ⏰ **完整时间戳** - 显示日期和时间

### 第二级功能
- 🔄 **消息撤回** - 鼠标悬停显示撤回按钮，点击撤回消息
- 🖼️ **用户头像** - 根据昵称自动生成彩色头像
- 👥 **私聊功能** - 支持一对一私密聊天，区分群聊和私聊

### 第三级功能
- 📷 **图片发送** - 支持发送图片，点击可放大查看
- 🏠 **多房间切换** - 支持创建和切换多个聊天室
- ✅ **消息已读状态** - 显示消息已读/未读状态

## 🛠️ 技术栈

- **前端**: HTML5 + CSS3 + JavaScript
- **后端**: Node.js
- **实时通信**: WebSocket (ws 库)
- **数据存储**: localStorage (客户端)

## 🚀 快速开始

### 环境要求
- Node.js (v14+)
- npm 或 yarn

### 安装步骤

1. **克隆项目**
   ```bash
   git clone <项目地址>
   cd simple-chat-app
   ```

2. **安装依赖**
   ```bash
   npm install
   ```

3. **启动服务器**
   ```bash
   npm start
   ```

4. **访问应用**
   打开浏览器访问 http://localhost:3000

### 使用方法

1. 打开 http://localhost:3000
2. 输入昵称，点击"进入聊天室"
3. 打开多个浏览器窗口，用不同昵称登录
4. 开始聊天！

## 🔧 自定义

### 修改端口
编辑 `server.js` 第 8 行：
```javascript
const PORT = 3000;  // 修改为你的端口
```

### 添加表情
编辑 `app.js` 第 31 行的 `emojis` 数组：
```javascript
const emojis = ['😀', '😃', '...'];  // 添加更多表情
```

## 📝 开发说明

### WebSocket 消息类型

| 类型 | 方向 | 说明 |
|------|------|------|
| `login` | 客户端→服务器 | 用户登录 |
| `message` | 双向 | 聊天消息 |
| `imageMessage` | 双向 | 图片消息 |
| `privateMessage` | 双向 | 私聊消息 |
| `typing` | 客户端→服务器 | 输入状态 |
| `stopTyping` | 客户端→服务器 | 停止输入 |
| `recall` | 客户端→服务器 | 撤回消息 |
| `readMessage` | 客户端→服务器 | 消息已读 |
| `createRoom` | 客户端→服务器 | 创建房间 |
| `joinRoom` | 客户端→服务器 | 加入房间 |
| `system` | 服务器→客户端 | 系统通知 |

### 数据存储

- **localStorage**: 保存聊天记录（最多 100 条）
- **服务器内存**: 保存当前在线用户列表和房间信息
